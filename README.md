# AppCatalog_RuStore

Android-приложение для каталога мобильных приложений, разработанное на Kotlin с использованием Jetpack Compose.

## Описание проекта

Проект представляет собой клиентское Android-приложение для просмотра каталога мобильных приложений.  
Пользователь может просматривать список приложений, фильтровать их по категориям, искать по названию, открывать карточку приложения и просматривать скриншоты.

## Реализованная функциональность

### Онбординг
- показывается только при первом запуске
- содержит логотип RuStore
- приветственный текст
- кнопку перехода на витрину

### Витрина приложений
- список приложений с иконкой, названием, кратким описанием и категорией
- переход в карточку приложения по нажатию
- кнопка перехода к списку категорий
- pull-to-refresh для обновления контента

### Экран категорий
- отображение списка категорий
- отображение количества приложений в каждой категории
- фильтрация витрины по выбранной категории

### Экран поиска
- строка поиска с автоматическим открытием клавиатуры
- интерактивный поиск по названию приложений
- при пустом результате отображаются популярные приложения

### Карточка приложения
- иконка
- название
- разработчик
- категория
- возрастной рейтинг
- полное описание
- горизонтальный список скриншотов
- кнопка "Установить" (в текущей версии как заглушка)

### Просмотрщик скриншотов
- открытие по нажатию на скриншот
- открытие с выбранного изображения
- горизонтальная прокрутка
- кнопка возврата в карточку приложения

### Дополнительно
- обработка состояний загрузки, ошибки и пустого списка
- Navigation Compose для навигации между экранами

## Используемые технологии

- Kotlin
- Jetpack Compose
- Navigation Compose
- Material 3
- SharedPreferences
- PullToRefreshBox

## Структура проекта

- `data` — моковые данные и сохранение состояния онбординга
- `model` — модели данных
- `navigation` — маршруты навигации
- `screens` — экраны приложения
- `ui.theme` — тема приложения

## Как запустить проект

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/e1n4ach/AppCatalog_RuStore
   ```
2. Открыть проект в Android Studio
3. Дождаться синхронизации Gradle
4. Запустить приложение на Android-устройстве или эмуляторе

## Особенности реализации

В проекте используются локальные mock-данные без подключения backend.
Функция установки приложения в текущей версии реализована как кнопка-заглушка.
Основной акцент сделан на обязательной части задания: экраны, поиск, фильтрация, навигация и устойчивость интерфейса к базовым ошибкам.
